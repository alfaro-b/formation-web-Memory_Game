# Memory Game 🎮

Un jeu de Memory développé en **HTML, CSS et JavaScript**, dans le cadre de ma formation en développement web.

L'objectif est de retrouver toutes les paires de cartes représentant des technologies du développement informatique.

## Fonctionnalités

- Trois niveaux de difficulté : facile (6 paires), moyen (8 paires) et difficile (10 paires).
- Cartes mélangées aléatoirement à chaque partie.
- Compteur de coups et de paires trouvées.
- Message de victoire en fin de partie.
- Possibilité de recommencer une partie.
- Interface responsive, conçue avec une approche Mobile First.

## Technologies utilisées

- **HTML5** : structure du jeu.
- **CSS3** : mise en page avec Flexbox, Grid et media queries.
- **JavaScript** : logique du jeu et manipulation du DOM.
